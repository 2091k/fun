# 配置选项说明

## 语音相关

| 选项 | 翻译 | 作用 |
|------|------|------|
| AGroupVoiceMicPrimaryIncrease | AGroup语音麦克风主音量增强 | 控制AGroup语音功能中麦克风主音量的增强程度，开启后可能提高麦克风采集声音的音量 |
| IMAudioMode | 即时通讯音频模式 | 设置即时通讯场景下的音频模式，如单声道、立体声等 |
| getAudioIncreaseDefaultNum | 获取默认音频增强数值 | 获取系统默认的音频增强数值，用于调整音频播放或录制时的音量大小 |
| getTtsIncreaseDefaultNum | 获取默认TTS增强数值 | 获取默认的文本转语音（TTS）音量增强数值，影响TTS语音播报的音量 |
| OpenAGroupMic | 打开AGroup麦克风 | 控制是否开启AGroup语音功能中的麦克风 |
| OpenAGroupVoiceCommFunc | 打开AGroup语音通信功能 | 决定是否启用AGroup语音通信功能 |
| XunFeiVoiceLine | 讯飞语音线路 | 指定使用讯飞语音服务时的线路，可能影响语音合成和识别的质量 |
